# WPS365 企业资料能力参考

WPS365 官方 CLI 同时覆盖多个业务域；本 Pi 技能仅使用“云文档连接”工具列表实际开放的文档操作，不代表可用 IM、邮箱、会议等其他功能。

| 文档业务 | 上游说明中的能力 | 使用边界 |
| --- | --- | --- |
| 云文档 | 驱动器、团队文档/文档库、文件查找、正文提取、版本及分享 | 先选择正确的资料位置；文档库权限和应用授权分别由服务端校验。 |
| 智能文档 | 新建/读取、块级读写、导入/导出 | 不把普通字符串当完整块结构；按真实 schema 处理。 |
| 智能表格 | 工作表、范围读写/查找、追加行 | 先明确表和范围，按返回范围判断是否已读全。 |
| 多维表 | 表结构、字段、记录增删改查与搜索 | 先读真实字段/记录结构，不能套用普通 Excel 的单元格参数。 |

这些是官方 CLI 能力概述，不是本地工具的静态名称或参数清单。`list_tools` 返回的工具和 schema 才是当前可调用范围；没有列出的能力，不能通过 CLI 的通用 api 命令或自选 HTTP 地址补绕。

工具较多时，先用 `list_tools` 的 `params.query` 按文档业务或工具名称筛选，再按实际 schema 调用。首批列表不一定覆盖全量能力。

上游有 delegated（用户授权）和 app（应用身份）两种认证。Pi 后端决定允许使用的身份，模型不得要求切换身份或提供凭据。企业商业权益不足与 OAuth scope 不足不是一回事，按返回的具体错误说明，不反复发起授权。

上游的 config init、auth login、spec/update 及凭据存储由管理员连接面板处理；技能不自行安装、登录、升级，也不执行 auth token 等输出密钥的命令。
