# Pi 云文档接入

管理员打开工作台 → **技能中心 → 云文档连接**。

1. 选择需要的平台，打开“授权指引”，在官方平台获取凭据。
2. 在本系统的“配置凭据”表单保存，再点“检测连接”。不要把 Token 或应用密钥发到聊天中。
3. 打开对应技能的“授权范围”，选择全部智能体或指定业务智能体，然后启用技能。
4. 在获授权的智能体里提供文档链接和任务，如“读取这份报价表，找出本周更新的行”。智能体先发现真实工具参数，再执行。

首次导入的三个技能默认停用；“修复技能”会保留已有技能的编号、启用状态、头像及共享范围。已有同名手动技能会被保留，需先备份更名。

## 平台差异

| 平台 | 身份与授权 | 本次适配 |
| --- | --- | --- |
| 腾讯文档 | 腾讯文档 MCP Token，受空间权限及官方会员要求限制 | 官方通用、Word、Sheet、PPT 四个 MCP 服务 |
| 金山文档 | 个人 WPS 账号的金山文档 Skill Token | 官方 kdocs-cli 2.7.1，受控文档工具目录 |
| WPS365 | 企业应用 ID、应用密钥，企业管理员授予对应 API 权限 | 官方 wps365-cli 0.3.6 的文档 MCP；当前使用应用身份 |

授权指引是官方网页说明，不是扫码登录状态；本页不会自动取得官网凭据。检测连接会执行最小的只读鉴权请求，不会修改云文档。平台权限不足或权益未开通时，会显示检测失败。

凭据使用 Windows CurrentUser DPAPI 加密保存于服务数据目录；需要使用原 Windows 用户启动服务。服务端不会把凭据注入模型提示词。工具调用仍受账号、群成员资格、技能启用状态、技能共享范围和智能体只读模式检查。工作区 PowerShell 本身仍有本机权限，此接入不构成操作系统沙箱。

当前不向模型开放 CLI 的认证、配置、更新、任意 API、任意本地文件或环境变量参数，也不开放 WPS 的邮件和 IM 功能。本地文件上传到云文档须另接现有群附件校验流程。

## 安装与维护

```powershell
npm run install:cloud-documents
npm run package:cloud-documents
```

CLI 与 MCP SDK 固定版本安装于 `.tools/cloud-docs/`，不修改系统 PATH，不覆盖个人 CLI 配置。安装脚本校验官方归档的 SHA256。技能包的来源、限制和工具调用契约见各技能的 `references/`。

原始上游材料审阅记录位于 `qa/vendor-docs-20261030/`，Pi 适配 ZIP 位于 `qa/cloud-docs-20261030/packages/`。WPS365 技能为本项目编写的官方 CLI 封装，并非上游发布的官方 Skill。
