# 腾讯文档品类与调用边界

腾讯文档官方 Skill 文档确认支持 Word、Excel、智能表格、智能文档的读取与编辑，以及文件/空间检索、创建和目录管理。连接返回的工具列表是本次实际能力，不保证目录里列出的所有操作已经开放。

| 用户任务 | 对应品类 | 调用前确认 |
| --- | --- | --- |
| 报告、会议纪要、在线段落编辑 | 智能文档（smartcanvas）或 Word（doc） | 先确认原文件类型和实际工具 schema；Word 与智能文档内容接口不同。 |
| 单元格、工作表、范围、公式 | Excel（sheet） | 明确目标工作表和范围，核实实际读写范围；不能声称只读首屏就已读完整文件。 |
| 业务记录、字段、视图 | 智能表（smartsheet） | 先取得真实表、字段和记录标识，再读写；不要把它当普通单元格表。 |
| 文件查找、移动、重命名、文件夹 | 通用文件/空间工具 | 通过返回的文件 ID 定位，名称重名时先消歧。 |
| PPT | 演示文稿（slide） | 仅在工具列表确有对应能力时处理；异步创建需查询真实状态。 |

官方 MCP 通用地址是 `https://docs.qq.com/openapi/mcp`；Word、Excel、PPT 的精细服务由服务端按已安装能力合并注册。Pi 使用 general.、word.、sheet.、slides. 前缀区分四类服务，前缀后仍须使用发现得到的确切工具名。AI 不自行添加服务地址或请求头，也不要求特定 MCP 客户端存在。上游 `get_content`、`smartcanvas.*`、`smartsheet.*` 等名称只用于理解路由；实际调用名称和参数以 `list_tools` 为准。列表过长或没有找到目标工具时，用 `list_tools` 的 `params.query` 按业务或名称筛选后再决定，不能把首批结果当全量能力。

空间 MCP Token 属于管理员连接配置，不是业务参数。官方获取 Token 页面当前要求超级会员/超级会员 Plus 校验，并说明空间 Token 有效期一年；不要承诺所有免费账号都能操作，按连接实测结果说明。
