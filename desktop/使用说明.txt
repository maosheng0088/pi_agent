PiConsole Windows 桌面版 0.2.1

1. 双击 PiConsole-Setup-0.2.1-x64.exe，安装到当前 Windows 用户。
   原 0.1.0 ZIP 试用版需安装一次新版，之后使用桌面的 PiConsole 快捷方式。
2. 使用原来的公司账号和密码登录，聊天、智能体、文件和任务与网页端同步。
3. 默认连接：https://ai.junweirpa.asia/
   在运行 Pi Web 的这台电脑上，也可通过“工作台 → 本机服务”连接 127.0.0.1:3210。
4. F11 切换全屏，Ctrl+R 重新连接或刷新，Ctrl+0 恢复原始大小。
5. 文件下载时选择保存位置；添加附件仍使用聊天输入框中的“添加附件”。
6. 登录状态独立保存在本机当前 Windows 用户中，不需要重新配置模型密钥。
7. 这是连接现有 Pi Web 的桌面客户端。任务、技能、定时调度继续由现有服务执行。
   关闭桌面端不会关闭服务器；服务器停止时，需要先恢复服务器再重新连接。
8. 客户端自动检查并下载更新，可在“帮助 → 检查客户端更新”手动检查。
   公司要求的必要更新不能跳过，下载完成后点击“安装并重新启动”。
   更新保留现有账号登录状态；网页界面更新无需重新下载安装包。

桌面端设置与登录状态：%APPDATA%\PiConsole
源码目录：D:\code\pi-web\desktop
